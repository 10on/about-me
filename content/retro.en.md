### Toshiba Satellite 2750

The first laptop in the collection. Picked it up on the principle of "an old laptop with a floppy drive, CD-ROM, and the most ports possible." Now it's my main working retro machine — the most polished and the most powerful.

#### Configuration

- Pentium III
- 192 MB RAM (64 onboard + 128 module)
- 64 GB SSD via IDE → SATA → M.2
- USB, COM, LPT, FDD
- Partially working battery, original power adapter

#### Status

Fully operational. Running Windows 98 and Windows XP. Chronic problem: the CD-ROM. The original one died, the replacement from eBay didn't last long either, and a third drive is waiting to be installed — which requires almost a full teardown.

#### To do

- Install the third CD-ROM (a compatible one per the documentation)
- Image the system drive once it's fully configured
- Restore the battery if needed

### Epson ActionNote AC500

The second laptop, from 1994. Color passive-matrix display, a Cyrix 486-class chip (actually a fast 386 with extended capabilities). One of the most interesting projects in terms of hardware mods.

#### Configuration

- Cyrix 486-class, 4 MB RAM
- Math coprocessor (installed)
- CF storage
- Memory expansion slot

#### Status

Working. Fully disassembled and cleaned, the main components are in good shape. The battery doesn't work. The main limitation is the 4 MB of memory.

#### Done

- Dallas RTC mod: drilled the case, routed external battery power, installed a holder
- Installed a math coprocessor

#### In progress

**A 4 MB memory module.** Finding an original one is basically impossible. Got photos of the module from both sides, bought the chips — planning to design my own.

**Battery repacking.** Identified the cell type, ordered from AliExpress. The contacts and sensors from the original battery are intact.

**CF card configuration.** Need to sort out a stable configuration, and check whether two devices are supported on one IDE channel (Master/Slave).

### Toshiba T3200SX

One of the newest additions, not explored much yet. Gas-plasma display, 386SX. Planned as a big long-term project — the main experimental platform for ISA development.

#### Configuration

- 386SX, currently 3 MB RAM
- Bought 4 more 1 MB modules
- Two ISA slots
- Have an ISA network card, an ISA sound card is on the way

#### Status

Working, no serious faults found. Screen is in good shape. Still barely explored so far.

#### To do

- Full teardown, cleaning, maintenance
- Install additional memory modules (up to 6+ MB)
- Check whether a coprocessor can be installed
- Set up networking (ISA card is on hand)
- Set up sound (card is on the way)

#### ISA project

I want to design my own ISA card — inspired by the [3inONEder for Toshiba portables](https://conventionalmemories.com/wiki_cm/3inONEder_for_Toshiba_portables), though not to copy it, but to build one for my own needs. Bought a blank ISA board.

Directions: working with modern storage, networking features, interfaces for LEGO projects, digital and analog I/O.
